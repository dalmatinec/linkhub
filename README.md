# linkhub — бот-каталог магазинов

Telegram-бот-каталог: разделы (Премиум, Топы, …), выбор города, списки магазинов, карточки с медиа и контактами.
**В коде нет ни одного текста или кнопки** — всё хранится в базе и меняется из админки прямо в боте:
тексты с премиум-эмодзи, кнопки (текст, иконка-эмодзи, цвет, порядок, ряды), разделы, города, магазины.

## Запуск

```bash
cp .env.example .env        # впишите BOT_TOKEN и OWNER_IDS
pip install -r requirements.txt
python -m bot
```

Или в Docker: `docker compose up -d --build` (данные лежат в `./data`).

Админка — команда **/admin** (видна только админам).

## Как это устроено для пользователя

```
/start → приветствие (текст + фото/GIF/видео по желанию)
 ├─ 💎 Премиум   → магазины с меткой «Премиум» (все города)
 ├─ 🔥 Топы      → магазины с меткой «Топ»
 ├─ 🏙 Выбрать город
 │    ├─ Алматы        Астана
 │    ├─ Шымкент       🌍 Другие города → остальные города, по 2 в ряд, со страницами
 │    └─ ◀️ Назад
 └─ 🔍 Поиск     → по названию и описанию («vpn», «подарки»…)
Город → магазины: сначала Премиум, потом Топ, потом остальные
Магазин → карточка: медиа, текст, контакты, «Пожаловаться», «Назад»
```

- Списки — по 2 кнопки в ряд, со страницами ◀️ 1/3 ▶️ (число в ряду и на странице настраивается).
- В чате всегда **один экран**: бот редактирует сообщение, а если нельзя (текст ↔ медиа) — присылает новое
  и удаляет старое. Сообщения пользователя (/start, случайный текст) удаляются.
- Прямая ссылка на магазин: `t.me/<бот>?start=shop_12` — есть в карточке магазина в админке.

## Админка

| Раздел | Что можно |
|---|---|
| 🏪 Магазины | создать, текст карточки, медиа, контакты, метки со сроком, города, «Проверенный», скрыть/опубликовать, порядок, предпросмотр, статистика просмотров |
| 📋 Меню | любые кнопки и подменю: текст, иконка, цвет, ряд, порядок, тип (подменю / метка / все магазины / города / поиск / ссылка) |
| 📝 Тексты и кнопки | приветствие и все системные тексты, «Назад», «Другие города», стрелки страниц |
| 🏙 Города / 🏷 Метки | главные и «другие» города, порядок; метки = подборки (Премиум, Топ, свои) |
| 👥 Пользователи | поиск, бан на время/навсегда, разбан |
| 📣 Рассылка | любое сообщение всем пользователям |
| 📊 Статистика | пользователи, просмотры, топ магазинов |
| 🚩 Жалобы | жалобы пользователей на магазины |
| 🛡 Защита / ⚙️ Настройки | антифлуд, автобан, чистка чата, размеры списков, лимит медиа, часовой пояс |
| 💾 Бэкап | архив сейчас / автоматически раз в сутки, восстановление |
| 👮 Админы | модераторы с правами по разделам (галочками) |
| 📜 Журнал | кто и что менял |

**Премиум-эмодзи.** Просто отправьте боту текст с премиум-эмодзи — он сохранит его как есть.
Для кнопок первое премиум-эмодзи в сообщении становится иконкой кнопки (ID бот определяет сам).
Telegram показывает премиум-эмодзи от бота, если у **владельца бота есть Telegram Premium**
(или у бота куплен юзернейм на Fragment).

**Ассортимент в два клика:** Магазины → магазин → «📝 Текст карточки» → отправили новый текст.

## Медиа и переезд

- Медиа (JPG, PNG, WEBP, GIF, MP4, до 10 МБ — настраивается) хранятся **оригиналами** в `data/media`,
  а `file_id` — отдельно для каждого бота.
- **Новый токен:** замените `BOT_TOKEN` в `.env` и перезапустите. Бот увидит, что он «новый», и в фоне
  перезальёт все медиа. Если `file_id` не сработал или файла нет — экран покажется без падения
  (без медиа), а админ получит уведомление.
- **Новый сервер:** перенесите папку `data` целиком, либо восстановите из архива:
  в админке «💾 Бэкап → Восстановить» (архив до 20 МБ) или на сервере
  `python -m bot.restore data/backups/backup_....zip` (бот остановлен).
- Пользователи нового бота должны один раз нажать /start — это ограничение Telegram.
  Держите ссылку на актуального бота в своём канале.

## Для разработчика

```
bot/
  __main__.py     запуск, сборка приложения
  db.py           SQLite (WAL), миграции схемы — новые добавлять в конец MIGRATIONS
  seed.json       начальные данные (заливаются в пустую базу; новые тексты — при каждом старте)
  catalog.py      кэш каталога в памяти, перечитывается после каждой правки в админке
  media.py        хранение медиа и file_id по ботам
  ui.py           клавиатуры, пагинация, показ экрана (edit / send+delete)
  middlewares.py  учёт пользователей, бан, антифлуд — до основной логики
  jobs.py         сброс статистики пачками, сроки меток, истёкшие баны, автобэкап
  handlers/user.py        пользовательская часть
  handlers/admin/core.py  движок админки: @view / @action / @on_input, права
```

Производительность: пользователи читают только из памяти; `last_seen`, просмотры и id экранов копятся
в памяти и пишутся в базу пачкой раз в 30 секунд; на всех выборках есть индексы.

Тесты (бот целиком на фейковом Telegram API): `pip install -r requirements-dev.txt && python -m pytest -q`
