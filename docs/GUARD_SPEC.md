# Модератор для Бакси: ТЗ

Отдельный Telegram-бот, который наводит порядок в чатах. Живёт в своём репозитории, на том же сервере, что и Бакси
(dalmatinec/baxi, раньше назывался linkhub; папка на сервере /opt/linkhub и сервис linkhub остались прежними), со своей базой. С Бакси общается через внутренний API (раздел 6).

Зачем отдельно: Бакси в чатах выглядит как живой человек, а модератор мутит и банит, это всегда видно как бот.
Бакси не нужны права админа, модератору нужны. Падение одного не трогает другого.

## 1. Правила проекта (обязательно)

- Python 3.12, aiogram 3.27+, aiosqlite (SQLite в режиме WAL), httpx, aiohttp для внутреннего API.
- Репозиторий публичный: токен, ключи и ID только в `.env` на сервере. В коде и в GitHub секретов нет, есть `.env.example`.
- Владелец бота определяется только по Telegram ID (`OWNER_IDS` в `.env`), никогда по имени или юзернейму.
- В текстах бота никогда не ставить длинное тире и кавычки-ёлочки: дефис, запятая, обычные кавычки.
- Тексты от имени «🛡 Модерация», нейтрально и коротко. Никаких шуток про национальность и религию.
- Модератор не дублирует Бакси: никаких /me, триггеров, игр, монет, репутации, приветствий. Только порядок.
- Всё новое в чате по умолчанию выключено, кроме ручных команд для админов. Админ включает сам.
- Тесты: pytest на чистую логику (разбор времени, нормализация слов, поиск ссылок), ruff `--select F,E9,B`.

## 2. Кто может пользоваться

| Кто | Что может |
|---|---|
| Участник | ничего, бот для него невидим, пока не нарушит |
| Админ чата с правом ограничивать участников | все команды модерации в своём чате, настройки чата в ЛС |
| Создатель чата | то же, плюс /whitelist и выдача модераторов бота |
| Владелец бота (OWNER_IDS) | всё во всех чатах, /admin в ЛС |

Права проверять через `get_chat_member` с коротким кешем (минута). Перед действием проверять и права самого бота,
при нехватке писать, какого права не хватает.

## 3. Команды

Цель указывается ответом на сообщение (основной способ), либо `@username`, либо числовым ID после команды.
Время: `30m`, `2h`, `3d`, `1w`, без времени у /mute это 1 час, у /ban навсегда. Причина: всё, что после времени.

| Команда | Что делает |
|---|---|
| /mute [время] [причина] | запретить писать на время |
| /unmute | снять мут |
| /warn [причина] | предупреждение; на N-м (по умолчанию 3) автоматически бан или мут, как настроено |
| /warns | показать предупреждения человека (ответом) или свои |
| /unwarn | снять одно последнее предупреждение |
| /ban [время] [причина] | забанить, опционально на время |
| /unban | разбанить |
| /kick | выгнать без бана (ban + сразу unban) |
| /pin, /unpin | закрепить или открепить сообщение, на которое ответили |
| /link | создать ссылку-приглашение |
| /del | удалить сообщение, на которое ответили, и саму команду |
| /whitelist | ответом: добавить или убрать человека из белого списка; без ответа: показать список |
| /settings | в ЛС: настройки модерации своих чатов; в группе: кнопка-ссылка в ЛС |
| /chat | в группе: ID чата, режим, каких прав не хватает боту |
| /v | пинг |

Сама команда удаляется через несколько секунд, ответ бота тоже (настраивается), чтобы не засорять ленту.
Предупреждения сгорают через N дней (по умолчанию 30, настраивается, 0 значит не сгорают).

## 4. Автоматическая защита (каждая включается отдельно)

**Стоп-слова.** Список слов на чат. Перед сравнением текст нормализуется: нижний регистр, ё в е, латинские
двойники букв в кириллицу (a→а, o→о, e→е, p→р, c→с, x→х, y→у, k→к, m→м, t→т, h→н, b→в), убрать повторы букв
(«плохоооой» → «плохой»), убрать знаки между буквами («п.л.о.х.о»). Действие: удалить, удалить и предупредить,
удалить и замутить. Проверять и отредактированные сообщения.

**Антиспам и антискам.** Для всех, кроме админов и белого списка:
- ссылки на сайты (кроме доменов из белого списка доменов чата), приглашения `t.me/+`, `t.me/joinchat`,
  ссылки на чужие каналы и боты, упоминания `@канал`;
- пересылки из каналов и от других людей;
- кнопки-ссылки (inline keyboard) в чужих сообщениях;
- типовые скам-признаки: «заработок в день», «пиши в лс», «бесплатно раздаю», крипто-кошельки, номера карт.
Новичкам (первые 24 часа в чате или первые 5 сообщений) строже: любая ссылка удаляется.
Спорные случаи можно отдать нейросети, но только их и с дневным лимитом, по умолчанию нейросеть выключена.
Действие на выбор: удалить, удалить и предупредить, удалить и замутить на час, бан.

**Белый список** (/whitelist): этим людям можно ссылки и пересылки. Отдельно белый список доменов в настройках.

**Чистка служебных сообщений:** вошёл, вышел, закрепил, сменил фото или название чата. Каждое отдельной галкой.

**Режим атаки:** при набеге. Пока включён, каждого нового участника сразу выгоняет (ban + unban). Включается
кнопкой в настройках или командой /attack, сам выключается через 30 минут (настраивается).
Автовключение (опция): больше 10 входов за минуту.

**Журнал:** каждое действие пишется в базу. В настройках можно указать чат или канал для журнала, туда идёт
короткая строка: кто, кого, что, причина, ссылка на сообщение.

## 5. База (своя, SQLite)

- `chats`: chat_id, title, все настройки из раздела 4, warn_limit, warn_action, warn_ttl_days, log_chat_id,
  attack_until, created_at.
- `warns`: id, chat_id, user_id, by_id, reason, ts, active.
- `actions`: id, chat_id, user_id, by_id, kind (mute, unmute, warn, unwarn, ban, unban, kick, delete, spam),
  until, reason, ts. Это журнал, чистить старше 90 дней.
- `stopwords`: chat_id, word.
- `whitelist`: chat_id, user_id, added_by, ts.
- `domains`: chat_id, domain.
- `outbox`: события для Бакси, которые не удалось отправить (раздел 6).
- `kv`: служебные значения.

## 6. Внутренний API между ботами

Оба бота поднимают маленький HTTP-сервер (aiohttp) **только на 127.0.0.1**, снаружи его нет.
Каждый запрос с заголовком `X-Key: <BAXI_API_KEY>`, ключ одинаковый в `.env` обоих ботов. Нет ключа: 401.
Всё в JSON, время в unix-секундах.

`.env` модератора: `GUARD_API_PORT=8711`, `BAXI_API_URL=http://127.0.0.1:8710`, `BAXI_API_KEY=...`.
`.env` Бакси: `BAXI_API_PORT=8710`, `GUARD_API_URL=http://127.0.0.1:8711`, `BAXI_API_KEY=...`.

**Сервер Бакси** (сделано: `bot/services/api.py` и `bot/services/guardlink.py`, связать ботов на сервере: `bash /opt/linkhub/deploy/guard-link.sh`):

- `GET /v1/chat/{chat_id}` → `{"known": true, "title": "...", "active": true, "paid": true, "trial": false,
  "free": false, "until": 1767225600}`. Модератор решает по этому, работать ли в чате платно
  (правило задаёт владелец в настройках модератора: `GUARD_NEEDS_BAXI_PAID=1` или своя подписка).
- `GET /v1/chat/{chat_id}/trusted` → `{"admins": [id, ...], "vip": [id, ...]}`. Их модератор не трогает автоматикой.
- `POST /v1/events` с телом
  `{"type": "warn", "chat_id": -100..., "user_id": 123, "by_id": 456, "until": 0, "reason": "...",
  "warns": 2, "warn_limit": 3, "ts": 1763400000}`.
  Типы: warn, unwarn, mute, unmute, ban, unban, kick, spam. Ответ `{"ok": true}`.
  Бакси использует это так: в /me «⚠️ предупреждения 2/3», не отвечает замученному, в итогах дня «за день 2 мута»,
  по желанию подкалывает в своём характере.

**Сервер модератора:**

- `GET /v1/ping` → `{"ok": true, "version": "..."}`.
- `GET /v1/user/{chat_id}/{user_id}` → `{"warns": 1, "warn_limit": 3, "muted_until": 0, "banned": false}`.
- `GET /v1/chat/{chat_id}/stats?days=1` → `{"mute": 2, "warn": 3, "ban": 0, "kick": 0, "spam": 5}`.
- `GET /v1/chat/{chat_id}/settings` → какие защиты включены (для кнопки «🛡 Модерация» в карточке чата у Бакси).

**Надёжность:** если Бакси недоступен, событие кладётся в `outbox` и досылается раз в минуту (до 24 часов).
Если недоступен модератор, Бакси просто не показывает его данные. Таймаут запроса 3 секунды.
Пока Бакси без API, модератор работает сам по себе: все проверки «оплачен ли чат» считают чат разрешённым,
если `GUARD_NEEDS_BAXI_PAID=0`.

## 7. Меню в ЛС модератора

/start: короткое описание, кнопки «➕ Добавить в чат» (ссылка с запросом нужных прав администратора:
delete_messages, restrict_members, pin_messages, invite_users), «⚙️ Мои чаты», «📜 Команды».
Карточка чата: защита (стоп-слова, антиспам, служебные, режим атаки), предупреждения (лимит, действие, срок),
белый список, журнал. Один цвет акцента на экран. У владельца бота /admin: все чаты, сводка действий за день,
здоровье бота.

## 8. Деплой

- Папка `/opt/baxi-guard`, сервис `baxi-guard.service` (Restart=always, MemoryMax=150M, StartLimitIntervalSec=0 в [Unit]).
- `deploy/install.sh` и `deploy/update.sh` по образцу linkhub: git pull, зависимости, перезапуск, статус.
- Сначала тестовый бот и тестовая группа, живые чаты не трогать, пока владелец не скажет.

## 9. Порядок работы

1. Каркас: запуск, .env, база, /v, /chat, права.
2. Ручные команды раздела 3 с тестами разбора времени и цели.
3. Настройки в ЛС.
4. Автозащита раздела 4: стоп-слова, антиспам, служебные, режим атаки, журнал.
5. Внутренний API раздела 6 (сторона модератора) и outbox.
6. После этого в linkhub добавляется сторона Бакси.
